# MAID Protocol — Playtest Builds

This repository contains **work-in-progress playtest builds** of **MAID Protocol**.

MAID Protocol is a PC-98-inspired android maid management game currently in development.

## Current Build Status

The current build is a **playable work-in-progress prototype** focused on the core gameplay mechanics.

At this stage:

- Core gameplay mechanics are functional.
- The game is playable from start to finish as a basic prototype.
- Some UI and systems are still being developed.
- Events are **not fully configured yet**.
- Dialogue and character lines are **not implemented/configured yet**.
- English localization is **partial and unfinished**.
- Some content, visuals, text, and behavior are temporary.
- Many systems are still subject to change.

This build is primarily intended for **playtesting the current gameplay and core systems**, rather than representing the final game.

## Playtesting

You can download the latest build from the [Releases](../../releases) page.

Please keep in mind that this is an early development build. You will encounter unfinished content, placeholder elements, bugs, missing text, and things that may simply not work yet. Some of these are probably features. Some are probably bugs. At this stage, even the game is not entirely sure.

## What to Test

When playing, feedback about the following is especially useful:

- Core gameplay mechanics
- Controls and general usability
- UI and UX
- Tutorial and onboarding
- Incidents and decision-making systems
- System load / Heat / Stress mechanics
- Confusing or unintuitive interactions
- Bugs and unexpected behavior
- Performance and stability

## Reporting Bugs

Please use [GitHub Issues](../../issues) to report bugs or other problems.

When possible, include:

- Build version
- What happened
- Steps to reproduce the problem
- What you expected to happen
- Screenshot or video

A short report is completely fine. The important part is giving enough information to reproduce the problem.
